# stordeux.github.io

Page personnelle de Sébastien Tordeux — https://stordeux.github.io

- `index.html`, `style.css` : contenu et mise en page (bilingue FR/EN via les attributs `data-l`, bascule dans `i18n.js`)
- `hal.js` : publications chargées en direct depuis l'API HAL (idHal `sebastien-tordeux`)
- `cours/` : polycopiés, adresses stables `https://stordeux.github.io/cours/<nom>.pdf`
- `exposes/` : exposés

Mettre à jour un poly : `powershell -File maj_polys.ps1` (copie depuis Dropbox, commit, push).
